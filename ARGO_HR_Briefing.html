ARGO

HR Briefing: System Overview, Features, and Required API / Subscription Budget

Prepared from the current repository state on May 7, 2026

ARGO is an internal AI operations platform for ARP Global Capital. Its job is to reduce manual work around emails, market briefings, meetings, research, portfolio analysis, client follow-up, and macro event monitoring.

1. What ARGO Does Today

ARGO is built as one internal web application. Team members sign in with Microsoft 365, use browser pages for each workflow, and trigger AI-assisted actions behind the scenes through external APIs.

Email Intelligence

Pulls Microsoft 365 emails, classifies importance, tags them, and highlights what matters most.

Overnight Summary

Builds a morning briefing from overnight emails, market moves, and financial headlines.

Meeting Intelligence

Accepts transcripts or audio, transcribes meetings, extracts decisions, and creates action items.

Research Lake

Stores research documents, chunks them, embeds them, and supports semantic search and Q&A.

Portfolio Intelligence

Tracks positions and generates AI scenario analysis and trade ideas.

Client / Sales Intelligence

Acts as a lightweight CRM for investors, prospects, and relationship follow-ups.

Research Intelligence

Summarizes broker or internal research, rates conviction, and builds a digest.

Economic Intelligence

Tracks macro events and generates release-impact commentary when actual data arrives.

AI Assistant

Provides a chat interface so team members can ask ARGO questions in natural language and be routed toward the most relevant module.

In plain terms: ARGO saves staff time by replacing repeated manual triage, summarization, and search work with a single internal system.

2. Why Paid APIs and Credits Are Needed

ARGO does not generate AI outputs by itself. It orchestrates other paid services. Those services charge by token, minute, message, or query.

Service What ARGO uses it for Why credits are necessary
Anthropic Claude Email tagging, meeting summaries, overnight briefings, research summaries, portfolio scenarios, assistant routing/chat Every AI text task sends tokens to Claude and is billed on usage.
OpenAI Whisper speech-to-text and document embeddings for semantic search Audio transcription and embeddings are metered usage features.
Twilio WhatsApp Sending overnight summaries and macro alerts to WhatsApp recipients WhatsApp messages are billed per message, plus Meta pass-through fees in some cases.
Serper Real-time web/news search used by the overnight summary Search calls consume credits after the free allowance.
Microsoft 365 / Azure AD Login, mailbox access, and sending email via Microsoft Graph ARGO requires an existing corporate Microsoft environment. This is a platform dependency rather than a token-credit API line item.
AWS Production hosting, container deployment, and production database Needed for a live production deployment, but separate from the AI usage budget.

3. Recommended Starter Budget

For a small initial rollout, a practical starting point is to pre-fund the AI and messaging services lightly, then scale once real usage is observed.

Line Item Starter Amount Reason
Anthropic Claude Sonnet 4.5 $20 Higher-quality reasoning tasks: overnight summary, meeting synthesis, portfolio scenarios, assistant replies
Anthropic Claude Haiku 4.5 $20 High-volume lower-cost tasks: email classification and lightweight routing
OpenAI Whisper-1 $20 Meeting audio transcription
OpenAI text-embedding-3-small $20 Research document embeddings for semantic search
Twilio $20 WhatsApp delivery buffer for briefings and alerts
Serper $50 minimum paid pack Serper offers 2,500 free queries, then its first paid top-up is $50 for 50,000 credits

Starter total: $150 if we fund all currently relevant paid services at a practical minimum.

If the goal is only to start testing internally, the team can initially rely on Serper's free 2,500-query allowance and defer the first paid Serper top-up. In that lighter version, the initial spend would be about $100 plus any existing Microsoft and hosting costs.

4. What $20 Buys for Each Service

Anthropic Claude Sonnet 4.5

Official pricing checked: $3 / 1M input tokens and $15 / 1M output tokens.

A rough business estimate: if one ARGO Sonnet task averages about 3,000 input tokens + 1,000 output tokens, that is about $0.024 per task. A $20 balance would cover roughly 830 similar tasks.

Anthropic Claude Haiku 4.5

Official pricing checked: $1 / 1M input tokens and $5 / 1M output tokens.

Using the same rough task size of 3,000 input + 1,000 output, the cost is about $0.008 per task. A $20 balance would cover roughly 2,500 similar tasks.

OpenAI Whisper-1

OpenAI's published Whisper price is $0.006 per minute of transcription.

A $20 balance covers about 3,333 minutes of audio, which is about 55.5 hours of meeting recordings.

OpenAI text-embedding-3-small

Official pricing checked: $0.02 / 1M input tokens.

This is extremely inexpensive relative to the rest of the stack. A $20 balance covers about 1 billion tokens of embeddings. For a typical internal research library, that is more than enough to start.

Twilio WhatsApp

Twilio's published WhatsApp fee is $0.005 per message, inbound or outbound. Meta may add template-message fees depending on message category and whether the message is inside or outside the customer service window.

  • Twilio fee only: $20 covers about 4,000 messages.
  • Example utility/auth message with Twilio + $0.0034 Meta fee: about 2,380 messages.

Serper

Serper currently advertises 2,500 free queries with no credit card required, and its first paid pack is $50 for 50,000 credits.

This means there is no real need to assign a $20 starter balance here. The platform can start on the free tier, then move to the first paid bundle when news-search usage becomes regular.
